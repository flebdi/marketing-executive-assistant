Format:

```
## YYYY-MM-DD: <decision>
- **Decision:** what was decided, in one or two sentences.
- **Why:** the reason, with the evidence behind it.
- **Decided by:** <name, role>
- **Alternatives considered:** <the options not chosen>
```

Gate override entries use the title `## YYYY-MM-DD: Override <gate> gate for <campaign slug>
at <score>` with the same fields.
