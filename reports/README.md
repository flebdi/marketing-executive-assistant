# Reports

Dated reports that cover more than one campaign.

- `daily/<YYYY-MM-DD>.md`: what's due today (QA re-checks, launches at risk, stuck campaigns,
  retros due), from the daily launch check routine. Only written when something is due.
- `weekly/<YYYY-MM-DD>.md`: weekly retro across all campaigns, from `/campaign-retro week`.
- `monthly/<YYYY-MM>.md`: expiring claims, stale context, and learnings to prune, from the
  monthly hygiene routine.
- `learnings-<YYYY-MM-DD>.md`: shareable summary of learnings, from `/learnings export`.

Single-campaign files live in that campaign's folder. Reports never contain contact-level data.
