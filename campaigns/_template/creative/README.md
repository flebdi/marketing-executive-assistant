# Creative

Drafts and final assets for this campaign.

- `variants/`: options generated by `/creative-shotgun`, one `<asset>.md` per asset, plus
  `compare.html` to see them side by side.
- `final/`: the picked version of each asset (`<asset>.md`), and the HTML export of each
  test send or page (`<asset>.html`) for QA. `/copy-review`, `/compliance-review`, and
  `/campaign-qa` read from here.
